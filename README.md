# Raw data and R script repository used in the study of the domestication of the sycamore tree using genomic data.


[![DOI](https://zenodo.org/badge/632084252.svg)](https://doi.org/10.5281/zenodo.23701087)


This repository contains the data in VCF, FASTA and PHYLIP format and the scripts used.


---
Data are in the '''data''' folder, and scripts used for the analysis can be accessed in the '''scripts''' folder.
